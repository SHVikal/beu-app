# BeU Branding

## App name

- `BeU`

## Core logo usage

- Use `Image("BeULogo")`
- Keep the logo on the BeU pink background
- Preserve aspect ratio with `.scaledToFit()`
- Do not stretch or crop the wordmark

## Color tokens

- Background: `#FADADD`
- Card background: `#FFF5F7`
- Logo/text: `#000000`

## Do

- Use the logo on pink background
- Keep spacing around the wordmark
- Use black text on pink
- Keep the icon centered with clear padding

## Don’t

- Stretch the logo
- Add shadows
- Add gradients
- Put the logo inside crowded cards
- Use white text on pink background

## Current asset names

- `BeULogo`
- `AppIcon`

## App icon

The iOS app icon uses the BeU wordmark centered on a full soft-pink background.
