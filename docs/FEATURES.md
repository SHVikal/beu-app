# BeU Features

## Core wellness dashboard
- Apple Health daily summaries
- readiness score and 7-day readiness trend
- daily action plan
- meal logging and nutrition progress
- streaks and consistency

## Nutrition
- onboarding for nutrition profile and targets
- daily calorie and protein counters
- meal photo logging with backend image analysis
- meal history
- weekly nutrition summary

## Profile features

### Supplements
- add, edit, pause, resume, and delete supplements
- reminders are shown in the daily action plan using user-entered timing only
- BeU never recommends supplements, dosage changes, or interactions

### Health history
- user-selectable health history conditions
- conditions only personalize wording and emphasis in the daily plan
- BeU never diagnoses, treats, or replaces medical guidance

## Safety constraints
- BeU provides general wellness guidance only and does not replace medical advice.
- no dosage, interaction, start, or stop language is used in supplement reminders
- no diagnosis or treatment claims are used in health-history personalization
- pregnancy, diabetes, eating disorder history, and other sensitive contexts only adjust wording and surface clinician-directed safety notes
