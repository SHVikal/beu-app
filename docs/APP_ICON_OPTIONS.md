# BeU App Icon Options

The app is now branded as `BeU`.

## Chosen Temporary Direction
Option 4 is the selected temporary icon direction for this build.

- Background: soft pink
- Foreground: large black stylized `B`
- Style: clean, minimal, scalable
- Reason: it stays legible at small sizes and matches the new premium wellness branding better than a longer wordmark

## Option 1: BeU Wordmark
- Pink background
- Bold black `BeU` text
- Minimal and premium

## Option 2: Mirror Symbol
- Pink background
- Abstract mirror shape
- Small `BeU` text
- Represents self-awareness and personal improvement

## Option 3: Heart + Spark
- Pink background
- Black heart outline with small sparkle
- Represents wellness and positive habit building

## Option 4: Letter B Monogram
- Pink background
- Large black stylized `B`
- Clean and scalable for app icon use

## Option 5: Plate + Spark
- Pink background
- Minimal plate outline with sparkle
- Represents food logging and nutrition guidance

## Temporary Implementation Note
This project currently does not include an app asset catalog with generated icon artwork, so the temporary icon direction is documented rather than exported as production-ready PNG assets.

To fully ship the icon:
1. Create an `Assets.xcassets` catalog.
2. Add an `AppIcon` set.
3. Export the chosen Option 4 monogram in the required iOS sizes.
4. Assign that icon set to the target in Xcode.
